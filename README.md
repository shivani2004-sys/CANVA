Task 1: UI/UX Layout and Wireframe Design
For Task 1, I started by developing the initial UI/UX layout and wireframes for the project. This involved extensive research to understand user needs and how the layout could serve both functionality and aesthetic appeal. I chose a minimalist approach to avoid overwhelming the user and focused on clarity in each screen’s design. The wireframes were created to demonstrate the basic structure of each page, ensuring that the flow between them was intuitive and user-friendly.
Once the wireframes were approved, I worked on refining the UI elements, including buttons, icons, and navigation. I ensured that the color scheme and typography aligned with the brand’s identity while remaining legible and accessible. This task laid the foundation for the entire project and set a solid direction for the user interface's development.

Task 2: User Research and Persona Development
In Task 2, I conducted user research through surveys and interviews, gathering valuable insights about the target audience’s preferences and pain points. I utilized this data to create user personas, which helped in understanding the various user groups and their specific needs. By focusing on these personas, I was able to tailor the design to meet the demands of each segment effectively.
The research process also involved analyzing competitors' designs to identify areas of improvement and opportunities for differentiation. This helped in making informed design decisions, ensuring that the app’s interface would stand out while solving real-world problems for users.

Task 3: Prototyping and User Flow Design
Task 3 involved translating the wireframes and research insights into a fully functional prototype. Using tools like Figma and Adobe XD, I created interactive prototypes that allowed users to visualize and test the app's flow. This included designing detailed screens and implementing navigation between them to simulate the end-user experience.
I also focused on mapping out the user journey, ensuring that the app’s flow was seamless and intuitive. The aim was to minimize friction by ensuring that users could complete tasks with minimal steps. This prototype was then tested with a few users, gathering feedback to refine the design and ensure the best possible user experience.

Task 4: AR Home Decor App & VR Meditation Room Design
For Task 4, I worked on designing the user interface for two different projects: an AR Home Decor app and a VR Meditation Room. The first task was to create the Splash/Welcome Screen and Checkout Screen for the AR Home Decor App. I ensured that these screens were visually appealing, easy to navigate, and aligned with the app's theme of modern, minimalist home decor.
For the VR Meditation Room, I designed an immersive yet calming interface that emphasized simplicity and tranquility. The layout focused on giving users an easy way to choose different relaxation environments, such as beaches or forests, in VR. I made sure that the navigation was intuitive and that the screens were responsive, ensuring a smooth experience across all devices.   
Both designs were made in Canva, considering the overall user experience, usability, and the emotional response that each app should evoke. I paid attention to color schemes, typography, and visual hierarchy to make each screen easy to understand while ensuring they communicated a sense of peace and comfort. The final designs were polished to a high standard and will be part of the final submission for the internship.
